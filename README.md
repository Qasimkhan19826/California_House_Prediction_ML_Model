# California House Price Prediction – Machine Learning

A Machine Learning project that predicts house prices in California using the California Housing dataset. The project focuses on the complete ML workflow, including data analysis, preprocessing, feature engineering, pipeline creation, and model training using Python and Scikit-learn.

## Project Overview

The goal of this project is to build a machine learning model that can estimate California house prices based on different housing and demographic features.

The project follows a structured machine learning workflow, starting from understanding the dataset and preparing the data to building and using a prediction model.

## Technologies & Libraries

- **Python** – Main programming language
- **NumPy** – Numerical operations
- **Pandas** – Data manipulation and analysis
- **Matplotlib** – Data visualization
- **Scikit-learn** – Data preprocessing, pipelines, and machine learning
- **Joblib** – Saving and loading trained models and pipelines

## Project Workflow

1. **Data Analysis:** Explore the dataset and understand its features and structure.
2. **Train-Test Splitting:** Split the dataset into training and testing sets.
3. **Data Visualization:** Visualize housing data to identify patterns and relationships.
4. **Data Preprocessing:** Handle missing values and prepare numerical features.
5. **Categorical Encoding:** Convert categorical attributes into numerical representations.
6. **Feature Scaling:** Apply feature scaling to prepare data for machine learning.
7. **Pipeline Creation:** Build preprocessing pipelines to automate data transformation.
8. **Model Training:** Train a machine learning model using the prepared dataset.
9. **Prediction:** Use the trained model and preprocessing pipeline to generate house price predictions.


## Learning Objectives

- Understanding the end-to-end machine learning workflow.
- Performing exploratory data analysis (EDA).
- Understanding train-test splitting and data leakage.
- Handling missing values and categorical attributes.
- Applying feature scaling.
- Building reusable preprocessing pipelines.
- Training and using machine learning models.
- Saving and loading trained models using Joblib.
